# 🌐 Personal Portfolio Website

Welcome to my personal portfolio website repository!  
This project showcases my skills, projects, and experience as a Front-End Developer in a clean, modern, and fully responsive design.

---

## 📌 About the Project

This portfolio was built to represent my professional profile, highlight my technical skills, and display selected projects in an attractive and user-friendly way.

It includes:

- Hero section with introduction
- Skills showcase
- Media section
- Projects / Portfolio section
- Reviews about me
- Contact section
- Fully responsive layout for all devices

---

## 🚀 Technologies Used

This project was built using:

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Design
- Sass (SCSS)

---

## 🎯 Features

- Clean and modern UI
- Fully responsive on mobile, tablet, and desktop
- Organized and maintainable code structure
- Smooth layout using Flexbox and Grid
- Styled efficiently using Sass
- User-friendly navigation
